`Accordion` is a stack of `<details>` elements. Each section opens and closes in the browser, with no script and with its keyboard. `.exclusive(name)` gives them a shared `name`, so opening one closes the others.

```rust
use navree::ui::*;

Accordion::new()
    .open_item("What does the plan include?", "Unlimited deals, 5 seats and the API.")
    .item("Can I change plans later?", "Yes, at any time.")
```

## When to use it

Use an accordion for several sections that readers open one by one, such as questions and answers.

## Keyboard and accessibility

<UiA11y>

| Key | Does |
|---|---|
| `Tab` | Moves between the sections' titles. |
| `Enter`, `Space` | Opens or closes a section. |

- Each title is a `<summary>`, announced as a button that is expanded or collapsed.
- The browser's find-in-page opens a closed section when it holds the match.

</UiA11y>
