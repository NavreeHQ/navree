`Progress` is the browser's `<progress>` element, styled. `Progress::new(value, max, label)` shows how far along something is; `Progress::indeterminate(label)` shows that it is going, with no known end.

```rust
use navree::ui::*;

Progress::new(640, 1000, "Importing contacts")
```

## When to use it

Use it when you know how much is done: an upload, an import, a step of a batch.

<UiChoose name="loading" current="Progress" />

## In a page

An import shows how many rows are done. The region asks the server again every two seconds, so the bar moves as the import works:

```rust
Region::new("import")
    .src("/fragments/import")
    .poll(Duration::from_secs(2))
    .children(Progress::new(640, 1000, "Importing contacts"))
```

The fragment the route answers draws the same `Progress` with the new value, and the region swaps it in.

## Tone and figure

`.tone(Tone)` colours the bar by what it means (`Tone::Success`, `Tone::Warning`, `Tone::Danger`). The colour never carries the meaning alone: the label says it. `.show_value()` writes the percentage beside the bar; a screen reader gets it from the bar itself, so the text is hidden from it. An indeterminate bar has no percentage to write.

```rust
Progress::new(640, 1000, "Importing contacts")
    .tone(Tone::Success)
    .show_value()
```

## Painted

`.fill(Gradient)`, `.ink(Ink)`, `.colors(ColorScale)`, `.goal(value)`, `.glow()`, `.height(px)` and `.motion(Motion)` draw the bar as a meter: an SVG track with a rounded fill in a gradient, a theme colour or the colour of its value's band, a goal marker, a glow, and a fill that grows in. It keeps the progress bar's role and values. Say the goal and what a colour means in the label as well.

```rust
Progress::new(402, 480, "Sleep, 6 h 42 min against a goal of 7 h")
    .fill(Gradient::horizontal().stop(0.0, Ink::slot(7)).stop_with_opacity(1.0, Ink::slot(7), 0.6))
    .goal(420)
    .height(12)
    .motion(Motion::new())
```

## Keyboard and accessibility

<UiA11y>

- The label is the element's `aria-label`; assistive technology reads the value as a percentage.
- To update it as work goes on, put it in a [region](/docs/ui/regions/) that polls.

</UiA11y>
