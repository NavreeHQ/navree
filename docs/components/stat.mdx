`Stat` shows one figure, what it is and, with `.trend(text, good)`, how it's moving: green when that's good news, red when it isn't. `Bars` draws a small bar chart as SVG on the server, with no script and no `style` attribute.

```rust
use navree::ui::*;

Stat::new("Open deals", "312").trend("+12 this week", true)
```

## A chart under the figure

`Stat::chart(...)` puts a small chart under the figure, usually a [Sparkline](/docs/components/sparkline/) of its last periods. For the other charts, see the [line chart](/docs/components/line-chart/).

<UiPreview example="sparkline/default" />

## A change

`Stat::trend(text, good)` writes how a figure moved in your own words. `Stat::change(Trend)` writes it as a [Trend](/docs/components/trend/): an arrow, the change with its sign, and a color for what it means, with `up_is_bad()` for figures where a rise is bad news.

```rust
use navree::ui::*;

Stat::new("Resting heart rate", "58 bpm").change(Trend::new(3.0).up_is_bad())
```

<UiPreview example="trend/default" />

## Keyboard and accessibility

<UiA11y>

- The trend's colour isn't its only sign: write the direction in the text, such as "+3.1%".
- A sparkline is a picture named by its title and described by its summary, with its values in a table that only a screen reader reads.
- `Bars` has `role="img"` and the description you give it, which is all assistive technology gets: say what the chart shows.

</UiA11y>
