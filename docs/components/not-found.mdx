`NotFound` fills the place of something that is gone: a deal that was deleted, a link that points nowhere.

```rust
use navree::ui::*;

Card::titled("Owner").body(NotFound::new().what("deal"))
```

`.what("deal")` names the thing: "This deal doesn't exist, or it was removed."

## When to use it

Use it for a part of a page. For a whole page, `UiModule` shows an [ErrorPage](/docs/components/error-page/) on a 404.

Choose between this and [Forbidden](/docs/components/forbidden/) by what the user may know. If seeing that the record exists would tell them something they should not know, answer 404 and show `NotFound`.

## One line

```rust

```
