`EmptyState` is for the three ways a list can be empty: there is nothing yet, a filter found nothing, or the work is done. Each says what to do next. It is built on the same markup as the [error states](/docs/ui/errors-and-states/), so a page of them looks like one family.

```rust
use navree::ui::*;

EmptyState::nothing_yet("deals")
    .description("Create a deal to start tracking your pipeline.")
    .action(Button::primary("New deal").icon(icons::PLUS))
```

## When to use it

Use it for a list, a table or a region. A [DataTable](/docs/ui/data-table/) takes an [Empty](/docs/components/empty/) with `.empty(empty)` and draws its own states for a filter that found nothing. Use `EmptyState` for lists you draw yourself.

## In a table

An empty table keeps its header. The state takes one cell that spans it.

<UiPreview example="empty-state/row" />

```rust
EmptyState::no_results().clear_filters("/deals").row(2)
```

## Keyboard and accessibility

<UiA11y>

- The headline is a paragraph, not a heading. Ask for a heading with `.heading(2)`.
- An empty list is not an error: it shows no status code.
- The icon is hidden from assistive technology.
- Only the actions you add take focus.

</UiA11y>
