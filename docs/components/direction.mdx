<UiPreview example="direction/default" />

`Direction::rtl(content)` sets `dir="rtl"` on a part of the page, and `Direction::ltr(content)` sets it back. Everything inside follows it: the text, the order of a row's items and which side a label sits on.

```rust
use navree::ui::*;

Direction::rtl(Text::new("שלום"))
```

## When to use it

Use it for a part of a page in another script: a customer's address, a quoted message. For a whole page in a right-to-left language, set the direction on the page.

<UiChoose name="divider" current="Direction" />

## In a page

A customer record in English holds an address that was written in Urdu. Only the address reads right to left:

```rust
Card::titled("Customer").body(Stack::gap(2).children((
    Text::new("Gurpreet Singh"),
    Direction::rtl(Text::new("لدھیانہ، پنجاب")),
)))
```

The card, its title and the name stay left to right. For a whole page in a right-to-left language, set the direction on the page.
