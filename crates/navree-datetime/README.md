# navree-datetime

Navree's dates and times: instants, calendar days, times of day, offsets and exact spans, with no third-party time crate under them.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is always part of `navree`, the framework crate, as `navree::datetime`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-datetime`.
