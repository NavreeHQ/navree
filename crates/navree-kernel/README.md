# navree-kernel

Navree kernel: module graph, type-keyed DI container, lifecycle and command runner.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is always part of `navree`, the framework crate, as `navree::kernel`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-kernel`.
