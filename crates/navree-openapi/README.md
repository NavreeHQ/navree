# navree-openapi

Navree's OpenAPI 3.1 document model and the ToSchema trait and derive that describe Rust types.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is always part of `navree`, the framework crate, as `navree::openapi`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-openapi`.
