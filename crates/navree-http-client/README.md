# navree-http-client

Navree HttpClientModule: outgoing HTTP with retries, timeouts, SSRF policy and fakes.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::http_client`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-http-client`.
