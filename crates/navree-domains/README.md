# navree-domains

Navree DomainsModule: workspaces on their own domains, verified through DNS, with automatic TLS certificates.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::domains`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-domains`.
