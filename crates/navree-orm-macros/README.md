# navree-orm-macros

Navree ORM macros: `#[derive(Model)]`, `#[scopes]` and `#[test]` (re-exported by navree-orm).

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

Its macros are re-exported by `navree-orm`, and so by `navree` with the `orm` feature. Depend on that crate instead of this one.

```sh
cargo add navree
```
