# navree-schema

Navree schema builder: tables, columns, indexes and foreign keys in Rust, compiled for PostgreSQL with TimescaleDB, MySQL/MariaDB and SQLite.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::schema`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-schema`.
