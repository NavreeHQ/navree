# navree-testing

Navree testing kit: TestApp, in-process TestClient with cookies and XSRF helpers, fakes.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::testing`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-testing`.
