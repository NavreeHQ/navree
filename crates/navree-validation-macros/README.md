# navree-validation-macros

Navree validation macros: `#[derive(Validate)]` with `#[validate(...)]` field rules (re-exported by navree-validation).

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

Its macros are re-exported by `navree-validation`, and so by `navree` with the `validation` feature. Depend on that crate instead of this one.

```sh
cargo add navree
```
