# navree-realtime

Navree RealtimeModule: Pusher-protocol WebSocket server with public, private and presence channels, and live server-sent event streams for pages.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::realtime`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-realtime`.
