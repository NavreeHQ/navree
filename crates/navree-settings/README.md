# navree-settings

Navree SettingsModule: typed settings stored per scope, inherited down the chain, with the source of every value.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::settings`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-settings`.
