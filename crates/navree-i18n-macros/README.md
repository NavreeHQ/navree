# navree-i18n-macros

Navree localization macros: embed_locales! embeds a directory of Fluent files in the binary, checking their syntax at compile time.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is always part of `navree`, the framework crate:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-i18n-macros`.
