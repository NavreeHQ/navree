# navree-search

Navree SearchModule: full-text and vector search over models, on the database, Meilisearch, Typesense, Tantivy or memory.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is opt-in. Turn on the `search` feature of `navree` to get `navree::search`:

```sh
cargo add navree --features search
```

You can also depend on it alone with `cargo add navree-search`.
