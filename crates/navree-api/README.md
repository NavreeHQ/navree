# navree-api

Navree ApiModule: OpenAPI 3.1 generation from route metadata, docs UI and API resource helpers.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::api`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-api`.
