# navree-workspace

Navree WorkspaceModule: multi-tenancy by workspace, with members, roles, invitations, and row, schema or database isolation.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::workspace`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-workspace`.
