Report a release

From a deploy script, with an access token that has lighthouse.configure. The label should be the one lighthouse.release gives the running processes, so issues and releases match.
curl -X POST {{ report_url }} \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"release": "20261102-101500-3f2a9c1", "commit": "3f2a9c1", "url": "https://git.example.com/crm/commit/3f2a9c1"}'
From the app's own code:
lighthouse.report_release(ReleaseReport::new("20261102-101500-3f2a9c1").commit("3f2a9c1")).await?;
