# navree-lighthouse

Navree LighthouseModule: application monitoring inside your app, with exceptions grouped into issues, traces, alerts and a dashboard.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::lighthouse`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-lighthouse`.
