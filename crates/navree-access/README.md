# navree-access

Navree AccessModule: roles, permissions and abilities with record checks and SQL list filters, shared with front ends as CASL JSON.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::access`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-access`.
