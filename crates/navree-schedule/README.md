# navree-schedule

Navree ScheduleModule: cron schedules, overlap prevention and single-node runs.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::schedule`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-schedule`.
