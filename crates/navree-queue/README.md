# navree-queue

Navree QueueModule: database and memory job queues, workers, retries with backoff, unique and delayed jobs, job batches and operations with progress.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::queue`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-queue`.
