# navree-cache

Navree CacheModule: cache stores (a bounded memory store), remember, tags, stale-while-revalidate and atomic locks.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::cache`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-cache`.
