# navree-macros

Navree's attribute and derive macros: `#[module]`, `#[injectable]`, `#[controller]`, route attributes, `#[agent]`, `#[workflow]` and more.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is always part of `navree`, the framework crate:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-macros`.
