# navree-auth

Navree AuthModule: JWT authentication with rotating refresh tokens, pluggable strategies and user accounts.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::auth`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-auth`.
