# navree-http

Navree HttpModule: Navree's router and extractors, default Tower layers, JSON errors, controllers and route metadata.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::http`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-http`.
