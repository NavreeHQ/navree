# navree-mail

Navree MailModule: mailables rendered from templates, SMTP and provider API transports, a delivery log, suppressions and inbound mail.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::mail`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-mail`.
