# navree-navigator

Navree Navigator: the MCP server for coding agents, with the app's routes, schema, logs and version-matched docs, and the agent skills.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is opt-in. Turn on the `navigator` feature of `navree` to get `navree::navigator`:

```sh
cargo add navree --features navigator
```

You can also depend on it alone with `cargo add navree-navigator`.
