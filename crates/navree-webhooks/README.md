# navree-webhooks

Navree WebhooksModule: signed outgoing webhooks with retries and a delivery log, and verified incoming webhooks from many senders.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::webhooks`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-webhooks`.
