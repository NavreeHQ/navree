# navree-storage

Navree StorageModule: named disks (local, memory, S3, Google Cloud Storage, Azure), streaming, signed and presigned URLs, upload checks and disk sync.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::storage`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-storage`.
