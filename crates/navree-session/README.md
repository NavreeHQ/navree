# navree-session

Navree SessionModule: encrypted session cookies, memory and database stores, CSRF protection.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::session`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-session`.
