# navree-sheets

Navree SheetsModule: CSV and Excel exports and import pipelines with header mapping, row validation, a preview and error files.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::sheets`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-sheets`.
