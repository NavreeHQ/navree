# navree-integrations

Navree IntegrationsModule: workspace connections to third-party APIs with admin consent, encrypted credentials, token refresh and typed clients.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::integrations`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-integrations`.
