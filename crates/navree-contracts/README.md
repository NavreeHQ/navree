# navree-contracts

Navree contracts: small cross-cutting traits and types (Secret, RequestId, Principal, sinks, jobs, clock).

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is always part of `navree`, the framework crate, as `navree::contracts`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-contracts`.
