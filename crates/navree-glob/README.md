# navree-glob

Navree's glob matcher: `*` and `?` over whole strings, in time proportional to the pattern times the input.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is always part of `navree`, the framework crate, as `navree::glob`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-glob`.
