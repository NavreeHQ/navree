# navree-billing

Navree BillingModule: subscriptions, trials, seats, metered usage and invoices for users or workspaces, with Stripe or Paddle.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is opt-in. Turn on the `billing` feature of `navree` to get `navree::billing`:

```sh
cargo add navree --features billing
```

You can also depend on it alone with `cargo add navree-billing`.
