# navree-workflows

Navree WorkflowsModule: durable workflows in code and end-user automations with triggers, conditions and actions.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::workflows`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-workflows`.
