# navree-validation

Navree ValidationModule: `#[derive(Validate)]` rules, `Valid<T>` extractors, field-level messages and international input.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::validation`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-validation`.
