# navree-native

The protocol of Navree Native: the parts, actions and ops a native client draws with its system's toolkit, the client descriptor, and example envelopes.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is a preview: what it holds may change in a minor release. Turn on the `ui-native-preview` feature of `navree` to get `navree::native`:

```sh
cargo add navree --features ui-native-preview
```

Depend on `navree` and not on this crate, so the two always fit each other.
