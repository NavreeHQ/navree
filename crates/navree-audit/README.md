# navree-audit

Navree AuditModule: audit trail of data changes, sign-ins and permission changes.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::audit`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-audit`.
