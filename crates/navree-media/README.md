# navree-media

Navree MediaModule: files attached to models, image conversions, safe remote downloads, zip archives and text extraction.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is opt-in. Turn on the `media` feature of `navree` to get `navree::media`:

```sh
cargo add navree --features media
```

You can also depend on it alone with `cargo add navree-media`.
