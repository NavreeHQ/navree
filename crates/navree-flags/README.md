# navree-flags

Navree FlagsModule: feature flags as types, resolved per user, workspace, plan or percentage, stored in the database and cached.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is opt-in. Turn on the `flags` feature of `navree`:

```sh
cargo add navree --features flags
```

You can also depend on it alone with `cargo add navree-flags`.
