# navree-mcp

Navree McpModule: MCP servers from `#[mcp_server]` services over streamable HTTP and stdio, with Navree auth and per-tool permissions.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is opt-in. Turn on the `mcp` feature of `navree`:

```sh
cargo add navree --features mcp
```

You can also depend on it alone with `cargo add navree-mcp`.
