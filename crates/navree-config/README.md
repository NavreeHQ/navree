# navree-config

Navree ConfigModule: typed configuration from .env, TOML and JSON files and APP_ environment variables.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is always part of `navree`, the framework crate, as `navree::config`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-config`.
