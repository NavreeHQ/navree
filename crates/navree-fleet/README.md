# navree-fleet

Navree FleetModule: supervised queue workers with auto-balancing, metrics, failed jobs and a Navree UI dashboard.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::fleet`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-fleet`.
