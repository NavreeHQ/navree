# navree-telemetry

Navree telemetry: typed events (requests, queries, jobs, mail and more) delivered to registered sinks, and W3C trace context.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::telemetry`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-telemetry`.
