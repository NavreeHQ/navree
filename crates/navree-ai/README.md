# navree-ai

Navree AiModule: text, structured output and streaming from many model providers, with failover, budgets, agents with tools and embeddings.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is opt-in. Turn on the `ai` feature of `navree` to get `navree::ai`:

```sh
cargo add navree --features ai
```

You can also depend on it alone with `cargo add navree-ai`.
