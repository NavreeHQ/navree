# navree-sso

Navree SsoModule: SAML 2.0 and OpenID Connect single sign-on per organization or workspace, verified email domains and just-in-time provisioning.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::sso`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-sso`.
