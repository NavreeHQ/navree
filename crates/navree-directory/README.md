# navree-directory

Navree DirectoryModule: a SCIM 2.0 server and directory pull connectors that sync users and groups into your app.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::directory`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-directory`.
