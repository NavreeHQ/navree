# navree-log

Navree LoggerModule: tracing subscriber, JSON or pretty output, redaction, rotating files and runtime level control.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::log`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-log`.
