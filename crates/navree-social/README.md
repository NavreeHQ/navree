# navree-social

Navree SocialModule: sign in with Google, GitHub, Apple, Microsoft and other providers, linked to Navree users.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is opt-in. Turn on the `social` feature of `navree` to get `navree::social`:

```sh
cargo add navree --features social
```

You can also depend on it alone with `cargo add navree-social`.
