# navree-ui-macros

The derives of navree-ui (Form, Options, TableRow and FilterBar), used through navree-ui or navree.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

Its macros are re-exported by `navree-ui`, and so by `navree` with the `ui` feature. Depend on that crate instead of this one.

```sh
cargo add navree
```
