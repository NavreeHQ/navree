# navree-view

Navree ViewModule: templates for mail and other text rendering.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::view`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-view`.
