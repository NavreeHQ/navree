# navree-logbook

Navree Logbook: a local debugging timeline of every request, query, job, mail and event, grouped by request, with request replay.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is part of `navree`'s default `full` feature set, as `navree::logbook`:

```sh
cargo add navree
```

You can also depend on it alone with `cargo add navree-logbook`.
