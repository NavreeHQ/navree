# navree-i18n

Navree I18nModule: Fluent translations with plurals and variables, negotiated per request, for validation messages, views and notifications.

Part of [Navree](https://navree.com), the complete application framework for Rust.

## Use it

It is opt-in. Turn on the `i18n` feature of `navree` to get `navree::i18n`:

```sh
cargo add navree --features i18n
```

You can also depend on it alone with `cargo add navree-i18n`.
