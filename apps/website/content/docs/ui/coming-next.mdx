---
title: "Coming next"
description: "The components and modules planned for Navree UI, in the order they come, with where each one stands."
---

Navree UI grows module by module, and each module ships only when it is finished. This is the order, and where each one stands. **Building** is under way, **next** starts as the modules being built ship, and **later** follows in this order. Until a module ships, its page doesn't exist and nothing here is a promise of its API.

| Order | Module | Status |
|---|---|---|
| 1 | [DataTable](/docs/ui/data-table/): sort, filter, page, select, bulk actions, export and stored views, from one definition | Shipped |
| 2 | Instant interactions: more of a page's interactions answered without waiting on the server | Shipped |
| 3 | [Select](/docs/components/select/), [Combobox](/docs/components/combobox/) with search on the server, [MultiSelect](/docs/components/multi-select/) and the [Command](/docs/components/command/) palette | Shipped |
| 4 | [Tabs](/docs/components/tabs/), [DropdownMenu](/docs/components/dropdown-menu/), [ToggleGroup](/docs/components/toggle-group/) and [Toast](/docs/components/toast/): titles, actions, a stack, pause, swipe and a live region | Shipped |
| 5 | [Calendar](/docs/components/calendar/), [DatePicker](/docs/components/date-picker/), [DateRangePicker](/docs/components/date-range-picker/) and [TimePicker](/docs/components/time-picker/): how they work is in [Dates and times](/docs/ui/dates/) | Shipped |
| 6 | [Themes](/docs/ui/themes/) and a [theme builder](/docs/ui/theme-builder/): seven built-in themes in light, dark or the device's mode, four shell layouts, and themes you build yourself | Shipped |
| 7 | [Errors and states](/docs/ui/errors-and-states/): error and sign-in pages drawn with Navree UI, and the states for a card, a region or a table row | Shipped |
| 8 | [Charts](/docs/components/line-chart/) and [Reports](/docs/ui/reports/): line, area, bar, donut, sparkline and funnel charts drawn on the server, and reports over a window from the address, in periods of a time zone, counted by the database | Shipped |
| 9 | [Wizard](/docs/components/wizard/) and [Stepper](/docs/components/stepper/): a form in steps with its progress kept in a draft on the server | Shipped |
| 10 | [Toolbar](/docs/components/toolbar/), [TreeView](/docs/components/tree-view/) and [Slider](/docs/components/slider/): one tab stop and a More menu, children loaded from the server, a range checked on the server | Shipped |
| 11 | [ContextMenu](/docs/components/context-menu/), [Menubar](/docs/components/menubar/) and [NavigationMenu](/docs/components/navigation-menu/) | Shipped |
| 12 | Rich text editing | Later |
| 13 | Islands: a part of a server-rendered page with its own JavaScript component | Later |
| 14 | [Icons](/docs/ui/icons/) and [Flags](/docs/ui/flags/): every Lucide icon as a constant the compiler checks, and a flag for every country, drawn inline | Shipped |
| 15 | [PhoneInput](/docs/components/phone-input/): a country list and a number box in one control, with the number read and checked on the server in the country chosen | Shipped |
| 16 | [LazyList](/docs/components/lazy-list/) and [SplitPane](/docs/components/split-pane/): a long list that loads by cursor as it is read and keeps the reader's place, and panes with separators people drag or move with the keys | Shipped |
| 17 | [Sortable](/docs/components/sortable/) and [drag and drop](/docs/ui/drag-and-drop/): lists and boards whose moves are posted and checked by the server, and live for other viewers | Shipped |
| 18 | The [live hub](/docs/ui/live-hub/): a page hears the topics it shows, scoped to the reader's user and workspace, and fetches the parts that changed | Shipped |
| 19 | [Markdown](/docs/components/markdown/) and [CodeBlock](/docs/components/code-block/): text from a model or a visitor drawn safely, and code with its colours | Shipped |
| 20 | [Upload](/docs/components/upload/): a drop area with progress, chunked large files and limits the server enforces | Shipped |
| 21 | [InputOtp](/docs/components/input-otp/) and [Carousel](/docs/components/carousel/) | Shipped |

## Until then

- **Anything else in the browser:** a [Next.js or Nuxt front end](/docs/ui/choosing-a-ui/) beside the same API.
