`Flag` draws a country's flag as inline SVG: no image request, no sprite, nothing to host. The set is [flag-icons](https://github.com/lipis/flag-icons) (MIT): the 249 ISO 3166-1 countries and Kosovo, the European Union and the United Nations, England, Northern Ireland, Scotland and Wales, Catalonia, Galicia and the Basque Country, and a few more places and bodies. 270 flags in all.

Type a country, a code or a word such as `region`.

## Name a flag

Like icons, a flag is a constant, so a binary holds the flags its code names and no others.

- **A constant**, `flags::AE`. Your editor completes it, and a code that does not exist does not compile.
- **`flag!("ae")`** takes the code as a person writes it, in any case, with `-` or `_` in `GB-SCT`. It is checked while your app compiles, and a code no flag has stops the build.
- **`Flag::country(code)`** is for a code that comes from data. It finds the flag in any case, and a code no flag has draws a neutral placeholder and never panics. Because the code could be any flag, this one call puts all of them in the binary.

```rust
use navree::ui::{Flag, flag, flags};

Flag::new(flags::AE)        // a constant
flag!("gb-sct")             // a literal, checked while the app compiles
Flag::country(&row.country) // data: the whole set comes along
```

A code is a `CountryCode`: a small `Copy` value that holds the code, the English name and the artwork. It sorts, hashes, prints, parses with `FromStr` and reads and writes as its code in serde, so it can sit in a form or a database column. `CountryCode::parse` returns an `Option`; `CountryCode::countries()` lists the countries for a picker.

## Sizes

The size is the width, on the same scale as Flux: 20, 24 (the default), 32, 40 and 48 px. A rectangle is a quarter shorter than it is wide.

<UiPreview example="flags/sizes" />

## Shapes

A flag is four by three, the way a flag is drawn. `FlagShape::Square` uses the artwork drawn for a square, which keeps the part of a flag that matters when it is cropped. `FlagShape::Round` is that square art cropped to a circle.

<UiPreview example="flags/shapes" />

## Regions and bodies

Not every flag is a country's. `CodeKind` says which: `Country`, `Region` (a nation of the UK, a region of Spain, an island group) or `Organisation` (the EU, the UN, ASEAN).

## Accessibility

By default a flag is an image whose name is the country's English name from Unicode CLDR: a flag alone in a table cell still says which country it is. Beside the country's name that would be read twice, so say `.decorative()` and the flag is hidden from assistive technology. `.label("...")` replaces the name, for a flag that stands for something else, such as a language.

## What they weigh

The artwork is inline, so a flag costs its bytes on every page it appears on. The median flag is 663 bytes (France is 143, the United States 548). 86 of the 270 are over 2 KB, 47 over 10 KB, and a few carry a coat of arms: Serbia is 175 KB, Bolivia 98 KB, Mexico 82 KB and Spain 77 KB. A table of two hundred rows of Serbia would carry Serbia two hundred times. Where one country repeats down a column, show its name in text and the flag only where it helps; browsers compress the repeats well on the wire, but the page still holds every copy.

## Where they come from

The artwork is flag-icons 7.6.0, recorded with its SHA-512 in `crates/navree-ui/icons.lock.json` and cleaned by `node crates/navree-ui/runtime/icons.mjs`: ids are made unique per flag and shape, so two flags on one page never share one, and styles, classes and anything that could load or run are removed. A flag keeps its colours in every theme; a faint outline keeps a white flag visible on a light page. The names are English names from Unicode CLDR 49 (Unicode License v3), and for six places and bodies CLDR does not name, flag-icons' own. Notices are in `THIRD_PARTY.md`.
