---
title: "Lifecycle hooks"
description: "Running code when the application boots and when it shuts down."
---

This page describes the `Lifecycle` hooks a provider can implement: `on_init` and `on_bootstrap` at boot, in module dependency order, and `on_shutdown` during a graceful shutdown, in reverse order.
