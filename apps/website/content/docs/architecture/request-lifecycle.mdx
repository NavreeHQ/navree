---
title: "Request lifecycle"
description: "What happens between a request arriving and the response leaving."
---

This page follows a request through a Navree application. It starts with the default Tower layers: request context, panic catching, timeouts, security headers, compression, error rendering, maintenance mode, rate limits and body limits. Then come authentication, the unit of work, the route's access check, extractors and your handler, and the response's way back out.
