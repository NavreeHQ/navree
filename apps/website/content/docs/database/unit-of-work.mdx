---
title: "The unit of work and transactions"
description: "One lazy transaction per request, committed when the request succeeds."
---

This page explains the unit of work: a lazy transaction per request that commits when the response succeeds and rolls back when it fails. It covers using it in handlers and services, how queued jobs and events wait for it to commit, and running transactions of your own.
