title: "Configuration reference"
description: "Every configuration section of the framework with its keys, types, defaults, environment variables and what each key does."
---

Every module of the framework reads one section of the configuration. This page lists them all: each key with its type, its default, the environment variable that sets it and what it does. It is written from the sections' own types and doc comments, so it cannot drift from the code.

A key is written under its section in `config/app.toml`, or in a file of its own, `config/<section>.toml`, without the section header. The environment variable of a key is `APP_`, the section, `__` and the key, in capitals; a dot becomes `__`, so `mail.smtp.port` is `APP_MAIL__SMTP__PORT`. A credential shows `secret` instead of a default: set it in `.env` or in the environment, not in a file that is committed. [How the sources combine](/docs/getting-started/configuration/) and [environment files](/docs/configuration/environments-and-files/) explain the rest.

`navree config:show --defaults` prints what an app uses, `navree config:publish <section>` writes a section's keys into a file of its own, and `navree config:schema` writes a JSON Schema for your editor.

## `api`

OpenAPI document and docs UI settings (configuration section `api`; every key optional).

More: [/docs/digging-deeper/openapi/](/docs/digging-deeper/openapi/).

| Key | Type | Default | Environment variable | Description |
|---|---|---|---|---|
| `title` | string | `"Navree API"` | `APP_API__TITLE` | The document title, `info.title` (default `Navree API`). |
| `version` | string | `"1.0.0"` | `APP_API__VERSION` | The API version, `info.version` (default `1.0.0`). |
| `servers` | list of string | `[]` | `APP_API__SERVERS` | Server URLs listed in the document (default none: clients use the URL they loaded the document from). From the environment, a comma-separated list (`APP_API__SERVERS=https://a.example,https://b.example`). |
| `docs_ui` | boolean |  | `APP_API__DOCS_UI` | Serve the API reference page at `{api_prefix}/docs`, when `openapi_json` is on too: the page shows what the document says. Public: nothing signs a reader in. Unset (`None`, the default), it follows the environment (see `serves_docs_ui_in`). |
| `openapi_json` | boolean |  | `APP_API__OPENAPI_JSON` | Serve the document at `{api_prefix}/openapi.json`. Public: anyone can read every documented route there. Off, nothing of it is served: not this route, and not the page. `openapi:export` writes the document either way. Unset (`None`, the default), it follows the environment (see `serves_openapi_json_in`). |
| `require_docs` | boolean | `false` | `APP_API__REQUIRE_DOCS` | Refuse to boot while a route has no `#[api]` documentation (default `false`; `navree check` reports undocumented routes either way). |
| `undocumented` | list of string | `[]` | `APP_API__UNDOCUMENTED` | Routes allowed without documentation: `"METHOD /path"` or `"/path"` (every method), with a trailing `*` matching any rest of the path (`"GET /storage/*"`). The path is the mounted one, prefix and version included. From the environment, a comma-separated list. |

## `audit`

The settings of `AuditModule`: the `audit` configuration section. Every key is optional.

More: [/docs/security/audit-log/](/docs/security/audit-log/).

| Key | Type | Default | Environment variable | Description |
|---|---|---|---|---|
| `enabled` | boolean | `true` | `APP_AUDIT__ENABLED` | Record audit entries at all (default `true`). When off, nothing is written; existing entries can still be listed and pruned. |
| `retention_days` | integer | `365` | `APP_AUDIT__RETENTION_DAYS` | How many days `audit:prune` keeps entries (default 365; 0 keeps them forever). |
| `skip_entities` | list of string | `[]` | `APP_AUDIT__SKIP_ENTITIES` | Tables whose changes are never audited, by table name (`sessions`) or subject type (`Session`), case-insensitively. The `audit_logs` table itself is never audited. |
| `skip_fields` | list of string | `["password","password_hash","token","token_hash","secret","two_factor_secret","two_factor_recovery_codes","remember_token"]` | `APP_AUDIT__SKIP_FIELDS` | Fields dropped from old and new values and metadata: a name (`ssn`, matched case-insensitively at any depth) or `table.field` (`users.phone`, top-level fields of one table or subject type). | `subject_types` | table of string | `{}` | `APP_AUDIT__SUBJECT_TYPES` | The subject type recorded for a table, overriding the default (the table name singularised in PascalCase: `deals` → `Deal`, `companies` → `Company`, `deal_notes` → `DealNote`). Actions are `<subject type in snake_case>.<created\|updated\|deleted>`. |
| `routes` | boolean | `true` | `APP_AUDIT__ROUTES` | Mount `GET {api_prefix}/audit` (default `true`). It requires the `audit.read` permission, so the app needs a `dyn RouteAuthorizer` (navree-access); turn it off in apps without one. |
