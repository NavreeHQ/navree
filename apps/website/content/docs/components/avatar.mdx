`Avatar` shows a person's picture with `Avatar::image(src, alt)`, or a neutral person icon with `Avatar::placeholder(label)`. There is no way to put initials in it.

```rust
use navree::ui::*;

Avatar::image("/avatars/ada.webp", "Ada Lovelace")
```

## When to use it

Use an avatar next to a person's name: in a list of members, a message, the user menu.

## Keyboard and accessibility

<UiA11y>

- An image avatar's `alt` is required. Next to the person's name, pass the name anyway: it's what a screen reader says if the picture is the only thing in a link.
- A placeholder has `role="img"` and the label you give it.
- Images load lazily and carry their width and height, so the page doesn't shift.

</UiA11y>
