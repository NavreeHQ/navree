`Alert` is a message that stays on the page: a title, a description and an icon chosen by its tone. Neutral and success alerts have `role="status"`; warning and danger alerts have `role="alert"`, which interrupts a screen reader.

```rust
use navree::ui::*;

Alert::new(AlertTone::Success)
    .title("Deal saved")
    .body("Acme renewal moved to Proposal.")
```

## When to use it

Use an alert for something about the page the reader is on: an archived record, a failed payment. After an action, a [toast](/docs/components/toast/) says it's done.

## Keyboard and accessibility

<UiA11y>

- `role="status"` is announced when the screen reader is idle; `role="alert"` at once. Keep warning and danger for what can't wait.
- An alert in the page when it loads is read with the page. The roles matter most for an alert that arrives later, in a [region](/docs/ui/regions/) or by an op.
- The icon is hidden from assistive technology: the title says what happened.

</UiA11y>
