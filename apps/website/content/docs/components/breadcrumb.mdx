`Breadcrumb` is a `<nav>` holding an ordered list of links, ending in the current page. The [app shell](/docs/ui/app-shell/) draws one in its top bar from `AppPage::crumb`.

```rust
use navree::ui::*;

Breadcrumb::new()
    .link("Deals", "/deals")
    .current("Sutlej Supply renewal")
```

## When to use it

Use a breadcrumb on pages deep in a hierarchy, so readers can step back up.

## Long trails

`.max_items(n)` keeps a long trail short. With more than `n` items (3 or more), the first item and the last `n - 2` show, and the ones between fold into an ellipsis that opens a list of them. It opens and closes natively, so it needs no script. `.hidden_label(text)` names the ellipsis for assistive technology (`Show hidden pages` by default).

```rust
Breadcrumb::new()
    .max_items(4)
    .link("Home", "/")
    .link("Accounts", "/accounts")
    .link("Punjab", "/accounts/punjab")
    .link("Ludhiana", "/accounts/punjab/ludhiana")
    .current("Sutlej Supply")
```

## Keyboard and accessibility

<UiA11y>

| Key | Does |
|---|---|
| `Tab` | Moves between the trail's links. |

- The `<nav>` is labelled "Breadcrumb"; `.label(name)` gives a second trail on the same page a name of its own, since landmarks must differ.
- The current page has `aria-current="page"` and isn't a link.
- `.prefetch()` fetches its links when the pointer rests on one or it takes focus, so the page is often there before the click. Off unless asked; only for pages whose `GET` changes nothing.

</UiA11y>
