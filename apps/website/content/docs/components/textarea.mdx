<UiPreview example="textarea/default" />

`Textarea` draws a `<textarea>` that posts as `name`. It grows with its text in browsers that size a field to its content.

```rust
use navree::ui::*;

Textarea::new("notes").rows(4).placeholder("What was agreed")
```

## When to use it

Use a textarea for text of more than one line: notes, a message, a description.

## Keyboard and accessibility

<UiA11y>

| Key | Does |
|---|---|
| `Tab` | Moves focus to the textarea. |
| `Enter` | Starts a new line; it doesn't submit the form. |
