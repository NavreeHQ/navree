`Kbd` writes a `<kbd>` element: a key to press, in a shortcut or an instruction.

```rust
use navree::ui::*;

Row::gap(1).children((Kbd::new("Ctrl"), "+", Kbd::new("K")))
```

## When to use it

Use it to name keys. For a status or a category, use a [Badge](/docs/components/badge/).
