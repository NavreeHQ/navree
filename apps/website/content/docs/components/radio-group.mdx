`RadioGroup` draws a `<fieldset>` with a `<legend>` and one native radio per choice, all posting as `name`.

```rust
use navree::ui::*;

RadioGroup::new("plan", "Plan")
    .option("starter", "Starter")
    .option("team", "Team")
    .selected("team")
```

## When to use it

Use a radio group when there are two to five choices and seeing them all helps. For more, use a [NativeSelect](/docs/components/native-select/).

## Keyboard and accessibility

<UiA11y>

| Key | Does |
|---|---|
| `Tab` | Moves focus into the group, to the chosen radio, and out again. |
| `↑`, `↓`, `←`, `→` | Moves to the next or previous choice and chooses it. |

- The legend names the group; each radio is named by its own label.
- `.required()` puts `required` on every radio, so the browser asks for a choice.

</UiA11y>
