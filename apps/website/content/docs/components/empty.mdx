`Empty` fills the space a list would take when there is nothing in it, and says what to do next.

```rust
use navree::ui::*;

Empty::new("No deals yet")
    .icon(icons::INBOX)
    .description("Create a deal to start tracking your pipeline.")
    .actions(Button::primary("New deal"))
```

## When to use it

Use it for a list, a table or a search with no results. A [DataTable](/docs/ui/data-table/) takes one with `.empty(empty)`.
