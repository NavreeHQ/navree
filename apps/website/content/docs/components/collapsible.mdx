`Collapsible` is one `<details>` with a title and a body: advanced settings, more about a record.

```rust
use navree::ui::*;

Collapsible::new("Advanced settings")
    .body(Switch::new("audit").label("Keep an audit log"))
```

## When to use it

<UiChoose name="disclosure" current="Collapsible" />

## In a page

A settings card keeps the common switch in view and tucks the rarely changed ones away:

```rust
Card::titled("Workspace settings").body(Stack::gap(4).children((
    Switch::new("digest").label("Send a daily digest"),
    Collapsible::new("Advanced settings").body(Stack::gap(3).children((
        Switch::new("audit").label("Keep an audit log"),
        Switch::new("sso").label("Require single sign-on"),
    ))),
)))
```

The section starts closed. Add `.open(true)` where most readers need it open.

## Keyboard and accessibility

<UiA11y>

| Key | Does |
|---|---|
| `Tab` | Moves to the title. |
| `Enter`, `Space` | Opens or closes it. |

- `.open(true)` starts it open. Its state is the browser's, so nothing posts back.

</UiA11y>
