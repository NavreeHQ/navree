A conversation is built from four pieces. `Message` holds an avatar, a header (who), its content and a footer (when). `Bubble` is what was said. `Marker` is a note between messages: a date, "joined the chat". An [Attachment](/docs/components/attachment/) sits in a message like a bubble. `BubbleSide::End` puts your own messages on the other side.

```rust
use navree::ui::*;

Message::new(BubbleSide::Start)
    .avatar(Avatar::placeholder("Ada Lovelace"))
    .header("Ada Lovelace")
    .content(Bubble::new(BubbleSide::Start, "Can we send the contract?"))
    .footer("10:42")
```

## Keyboard and accessibility

<UiA11y>

- Messages are plain elements read in order. Put the sender in the header and the time in the footer, so each message says who and when in words.
- The side a bubble leans to is only visual. Inside `Direction::rtl`, start and end swap.

</UiA11y>
