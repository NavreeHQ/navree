---
title: "Your first app"
description: "Build a small CRUD API with authentication and tests, from `navree new` to green tests."
---

This tutorial takes you from `navree new` to a working CRUD API. You generate a module with `navree make:module`, define an entity and its migration, add a controller with validation and access rules, sign users in with JWTs, and finish with feature tests that run against an in-process server.
